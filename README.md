## Descripcion del proyecto

El proyecto Software FJ consiste en el desarrollo de un sistema integral de gestion de clientes, servicios y reservas, utilizando el lenguaje de programacion Python y los principios de la programacion orientada a objetos.

El sistema permite registrar clientes, administrar servicios de reserva de salas, alquiler de equipos y asesorias especializadas, ademas de gestionar las reservas mediante operaciones de creacion, confirmacion, cancelacion y procesamiento.

## Objetivo

Implementar una aplicacion orientada a objetos que permita gestionar clientes, servicios y reservas, aplicando abstraccion, herencia, polimorfismo, encapsulacion y manejo de excepciones para garantizar la estabilidad del sistema.

## Tecnologias utilizadas

- Python 3
- Visual Studio Code
- GitHub

## Estructura del proyecto

- main.py: programa principal y pruebas.
- entidades.py: clases abstractas y gestion de clientes.
- servicios.py: servicios especializados.
- reservas.py: gestion de reservas.
- excepciones.py: excepciones personalizadas.
- logs.py: registro de eventos y errores.
- eventos.log: historial de ejecucion.
- README.md: documentacion del proyecto.

## Funcionalidades

1. Registro y validacion de clientes.
2. Gestion de servicios especializados.
3. Creacion de reservas.
4. Confirmacion y cancelacion de reservas.
5. Calculo de costos con descuentos e impuestos.
6. Control de disponibilidad.
7. Manejo de excepciones personalizadas.
8. Registro de eventos y errores.
9. Ejecucion de pruebas con datos validos e invalidos.

## Ejecucion

Para ejecutar el proyecto se debe abrir la terminal en la carpeta principal y escribir:

python main.py

## Almacenamiento

El sistema no utiliza bases de datos. La informacion se gestiona mediante objetos y listas internas. El archivo eventos.log almacena los eventos y errores generados durante la ejecucion.
